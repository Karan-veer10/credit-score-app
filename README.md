# 📖 Project Overview

The **Credit Score Prediction App** is a Machine Learning based intelligent web application designed to analyze a user's financial information and predict their credit score category accurately.

This project combines the power of:

* 🤖 Artificial Intelligence
* 📊 Data Analytics
* 💻 Full Stack Development
* 🧠 Predictive Modeling
* 📈 Financial Risk Analysis

The system helps users understand their financial reliability by processing multiple financial factors and generating smart predictions using trained Machine Learning models.

---

# 🎯 Objective of the Project

The main objective of this project is to create an AI-powered financial prediction system capable of:

✅ Analyzing financial behavior
✅ Predicting creditworthiness
✅ Automating financial assessment
✅ Demonstrating real-world ML implementation
✅ Providing an interactive and responsive user experience

This project was developed to understand how Machine Learning can solve real-world financial problems efficiently.

# 🚀 Installation & Setup Guide

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Karan-veer10/credit-score-app.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd credit-score-app
```

---

## 3️⃣ Create Virtual Environment (Optional)

```bash
python -m venv venv
```

### ▶ Activate Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

---

## 4️⃣ Install Required Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Run the Flask Application

```bash
python app.py
```
